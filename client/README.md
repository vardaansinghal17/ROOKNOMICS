# ♟️ Rooknomics Client Application

This directory contains the React 18 + Vite frontend for **Rooknomics**, the institutional-grade quantitative trading and backtesting engine.

## 🚀 Quick Start (Client)

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

For complete documentation, architecture, API reference, and setup instructions, please view the [Main Project README](../README.md).
